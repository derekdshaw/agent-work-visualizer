Navigation

Click a nodeIsolate it with callers and callees.
Callable filterScope focused nodes; Metaflow depth follows forward step transitions and includes direct dependencies.
Search resultsUse Up/Down to choose a callable, Enter to isolate it, and Escape to close results.
Ctrl + dragDraw a box and zoom the 3D view to enclosed nodes.
Ctrl + clickReset the 3D camera zoom.
Wheel or pinchZoom the active graph.
Labels On / OffShow or hide callable names beside 3D nodes.
↓ / ↑Decrease or increase depth through the selected callable's full connected component.
3D / 2DSwitch the focused graph rendering.
ModulesBrowse every source module and disconnected graph component; select a row to open its callable graph.
UnresolvedBrowse collapsed built-in, external/imported, and dynamic/unknown call-site sections.

Live agent view

FolderShows the folder that the page follows. Select it to choose a folder of a recent Claude Code session or a git worktree, or type a path. The server analyzes the folder and the page reloads. If the analysis fails, the page keeps the current folder.
GraphShows the callables that the agent read or edited, with up to 12 direct callers and callees each.
Yellow nodeCallables in the latest agent step.
Orange nodeEdited at least once.
Blue nodeRead, not edited.
Dim nodeNot touched. It calls or is called by a touched callable.
Green lineAgent trail. It joins the first callable of each step to the first callable of the next step, for the last 30 steps of each agent.
LayersShows one node for each source directory, sized by its callable count. Lines are calls between directories. Select a directory to open its callables.
ActivityLists every Read, Edit, and Write, newest first. Select a callable to isolate it and center it in the 3D view.
FollowWhen Follow is on, the graph adds the callables of the latest step. If no callable, scope, or search is selected, the camera centers the latest step and zooms until the step and its nearby callers and callees fill about half of the view. When Follow is off, the graph stays and the button counts the new steps.
TimelineStep back, play, and step forward through the agent steps, or drag the slider to a step. The graph, the call stack, the changes, and the task panel show the state at that step. Live returns to the latest step. The files do not change.
Pause agentHolds the next tool call of each followed session until you select Resume agent. A tool call that already runs and text that the agent writes do not stop. It needs the PreToolUse hook that sends tool calls to /gate.
Agent taskShows the session title, the latest request, the latest tool call, and each subagent with a tool call in the 2 minutes before it.
Call stackCallable names use the node colors. Select an edited callable to show its changes in this session, newest first, above its current source.
RefreshThe server analyzes the code again 2 seconds after the last edit. If the code does not parse, the previous graph stays.

Analysis

UnresolvedCall sites inside callables that could not be mapped to a callable defined in the analyzed source. Includes language runtime calls, external APIs, dynamic dispatch, and calls through runtime values.
